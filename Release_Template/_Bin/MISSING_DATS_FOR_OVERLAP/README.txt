Put your own text .dat files here (subfolders are allowed).
Every .tex path in them (e.g. Interface\DlgGoalsNoTabs.tex; text after // is ignored)
is exported with exportTilesetFromInterfaceOverlap and imported with
importTilesetToInterfaceOverlap, in every folder of Work.

Example (my_edge_cases.dat):
// textures that no .dat of the game names
Interface\DlgGoalsNoTabs.tex
Interface\MyOtherTexture.tex
